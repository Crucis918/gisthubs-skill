GistHubs 正式开张了 🎉 一句话:**把 GitHub 仓库里的内容,刷成小红书式的图文 Feed。**

现在打开就能用的功能:

- **游客免登录**:不用注册,打开首页直接刷所有公开内容
- **GitHub 一键登录**:OAuth 授权后即可互动、用网页 Skill 直接往自己仓库发内容
- **领域分类**:推荐 / 开发工具 / AI / 效率工具 / 技术教程 / 产品动态,按领域筛选
- **用户主页**:每个作者的仓库内容聚合在 `/user/用户名` 下

封面就是此刻的首页实拍,所有帖子都来自真实仓库的真实内容。

## 内容从哪来?

你的 README、更新日志、截图、教程 —— 只要按 `.gisthub/` 规范放进仓库,就会自动出现在 Feed 里。不写新东西,把你已有的项目资料整理进去就行。
